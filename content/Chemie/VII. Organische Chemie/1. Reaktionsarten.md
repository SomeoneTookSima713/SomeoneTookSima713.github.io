# Reaktionsarten organischer Chemie

## Substitution
Zwei Ausgangsstoffe reagieren miteinander durch den Austausch von kleinen Atomen oder Atomgruppen.

**Wichtig**: In der Reaktionsgleichung immer zwei Ausgangsstoffe und zwei Reaktionsprodukte!

**Wichtig 2**: Einfach-, Zweifach- und Dreifachbindungen bleiben gleich.

#### Beispiele
```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c l c r c l}
\ce{CH3-CH2-CH3} &+& \ce{Cl2} &$\rightarrow$& \ce{CH3-CH2-CH2-Cl} &+& \ce{HCl} \\
Propan &+& Dichlor &$\rightarrow$& 1-Monochlorpropan &+& Chlorwasserstoff
\end{tabular}
\end{document}
```

$~$

```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c l c r c l}
\ce{CH2=CH2} &+& \ce{HBr} &$\rightarrow$& \ce{CH2=CH-Br} &+& \ce{H2} \\
Ethen &+& Bromwasserstoff &$\rightarrow$& Monobromethen &+& Wasserstoff
\end{tabular}
\end{document}
```

## Addition
Zwei Ausgangsstoffe reagieren miteinander zu einem Reaktionsprodukt. Ein Ausgangsstoff *muss* eine Doppel- oder Dreifachbindung haben.

**Wichtig**: Eine Doppel- bzw. Dreifachbindung wird um mind. eins reduziert, indem sich der jeweils andere Ausgangsstoff an das Molekül anlagert.

#### Beispiele

```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c l c l}
\ce{CH2=CH2} &+& \ce{F2} &$\rightarrow$& \chemfig{[,0.75]CH_2(-[6,0.6]F)-CH_2-[6,0.6]F} \\[20pt]
Ethen &+& Fluor &$\rightarrow$& 1,2-Difluorethan
\end{tabular}
\end{document}
```

$~$

```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c c c l c l}
\ce{CH#C-CH_3} &+& \ce{Cl2} &+& \ce{I2} &$\rightarrow$& \chemfig{[,0.75]CH(-[2,0.6]Cl)(-[6,0.6]I)-C(-[2,0.6]Cl)(-[6,0.6]I)-CH_3} \\[20pt]
Propin &+& Clor &+& Iod &$\rightarrow$& 1,2-Dichlor-1,2-diiod-propan
\end{tabular}
\end{document}
```

## Eliminierung
Ein Ausgangsstoff zerfällt in zwei Reaktionsprodukte und ein Reaktionsprodukt hat eine Doppel- oder Dreifachbindung.

#### Beispiele
```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c r c l}
\ce{CH3-CH3} &$\rightarrow$& \ce{CH2=CH2} &+& \ce{H2} \\
Ethan &$\rightarrow$& Ethen &+& Wasserstoff
\end{tabular}
\end{document}
```

$~$

```latex {cmd=true hide latex_zoom=1.5}
\documentclass{standalone}
\usepackage{xcolor}
\usepackage{chemfig}
\usepackage{mhchem}
\usepackage{amssymb}
\usepackage{amsmath}
\color{white}
\begin{document}
\begin{tabular}{r c r c c c l}
\ce{CH3-CH2-CH2-Br} &$\rightarrow$& \ce{CH3-C#CH} &+& \ce{HBr} &+& \ce{H2} \\
1-Monobrompropan &$\rightarrow$& 1-Monobromprop-1-in &+& Bromwasserstoff &+& Wasserstoff
\end{tabular}
\end{document}
```
