# 4. pH-Abhängigkeit von Redoxreaktionen

## Versuch

Beobachtung:
* Natriumsulfit + Natronlauge → brauner Niederschlag
* Natriumsulfit + Wasser → brauner Niederschlag
* Natriumsulfit + Schwefelsäure → farblos

Deutung:
* Natriumsulfit + Natronlauge → Braunstein
* Natriumsulfit + Wasser → Braunstein
* Natriumsulfit + Schwefelsäure → Manganionen

---

**Der Verlauf von Redoxreaktionen ist abhängig vom pH-Wert**
