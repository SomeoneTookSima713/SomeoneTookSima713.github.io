# Korresponiderende Säure-Base-Paare

Eine *Säure-Base-Reaktion* ist eine unvollständige Reaktion im chemischen Gleichgewicht. Durch eine *Protonenabgabe* entsteht aus einer Säure $\ce{ HA }$ die korrespondierende Base $\ce{ A- }$. Durch seine *Protonenaufnahme* entsteht aus einer Base $\ce{ B }$ die korrespondierende Säure $\ce{ HB+ }$:
$$ \ce{ HA + B \rightleftharpoons A- + HB+ } $$

Es bilden sich *korrespondierende Säure-Base-Paare*.

An einer Protolyse sind immer 2 korrespondierende Säure-Base-Paare beteiligt.

### Beispiel
```latex {cmd=true hide latex_zoom=2}
\documentclass[varwidth]{standalone}
\usepackage{xcolor}
\usepackage{amssymb}
\usepackage{mathtools}
\color{white}
\begin{document}
\[
\lefteqn{\overbracket{\phantom{\textrm{HCL} + \textrm{H}_2\textrm{O} \rightleftharpoons \textrm{Cl}^-}}^\textrm{\small Säure-Base-Paar 1}}\textrm{HCL} + 
\underbracket{\textrm{H}_2\textrm{O} \rightleftharpoons \textrm{Cl}^- + \textrm{H}_3\textrm{O}^+}_\textrm{\small Säure-Base-Paar 2}
\]

HCl / Cl$^-$ // H$_2$O / H$_3$O$^+$
\end{document}
```
