# Licht und Schatten

## Lineare Lichtquelle (z.B. Sonnenlicht)
Langweilige Methode: Geradengleichung mit Stützpunkt des zu projizierenden Punktes und Richtungsvektor der Lichtrichtung aufstellen, dann Durchstoßpunkt mit der Ebene, auf die projiziert werden soll, ausrechnen.

Coole Methode: Eine Projektionsmatrix aufstellen

$$
\begin{align*}
\overrightarrow{ u } &= \begin{pmatrix}x_u\newline y_u\newline z_u\end{pmatrix}
\end{align*}
$$

Für die xy-Ebene
$$
M = \begin{pmatrix}
1 & 0 & -\frac{x_u}{z_u} \\
0 & 1 & -\frac{y_u}{z_u} \\
0 & 0 & 0
\end{pmatrix}
$$

Generell
$$
\begin{align*}
\overrightarrow{ OP } &= \begin{pmatrix}p_x\newline p_y\newline p_z\end{pmatrix} \\
E: n_xx + n_yy + n_zz &= d \\
g: \overrightarrow{ x } &= \overrightarrow{ OP } + t \overrightarrow{ u } \\
\overrightarrow{ n } \circ ( \overrightarrow{ OP } + t \overrightarrow{ u } ) &= d \\
\overrightarrow{ n } \circ \overrightarrow{ OP } + t \overrightarrow{ n } \circ \overrightarrow{ u } &= d \\
\rightarrow t &= \frac{d - \overrightarrow{ n } \circ \overrightarrow{ OP }}{ \overrightarrow{ n } \circ \overrightarrow{ u } } \\
\overrightarrow{ OP' } &= \overrightarrow{ OP } + \frac{d - \overrightarrow{ n } \circ \overrightarrow{ OP }}{ \overrightarrow{ n } \circ \overrightarrow{ u } } \cdot \overrightarrow{ u } \\
&= \overrightarrow{ OP } - \overrightarrow{ OP } \circ \left( \frac{ \overrightarrow{ n } }{ \overrightarrow{ n } \circ \overrightarrow{ u } } \right) \overrightarrow{ u } + \frac{d}{ \overrightarrow{ n } \circ \overrightarrow{ u } } \overrightarrow{ u } \\
&= \begin{pmatrix}
    \frac{d u_{x}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + p_{x} - u_{x} \left(\frac{n_{x} p_{x}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{y} p_{y}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{z} p_{z}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}}\right) \newline
    \frac{d u_{y}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + p_{y} - u_{y} \left(\frac{n_{x} p_{x}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{y} p_{y}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{z} p_{z}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}}\right) \newline
    \frac{d u_{z}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + p_{z} - u_{z} \left(\frac{n_{x} p_{x}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{y} p_{y}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}} + \frac{n_{z} p_{z}}{n_{x} u_{x} + n_{y} u_{y} + n_{z} u_{z}}\right) \\
\end{pmatrix} \\
f &\colonequals \overrightarrow{ n } \circ \overrightarrow{ u } \\
\overrightarrow{ OP' } &= \begin{pmatrix}
\displaystyle    p_x(1 - \frac{u_xn_x}{f}) - p_y\frac{u_xn_y}{f} - p_z\frac{u_xn_z}{f} + \frac df u_x \newline
\displaystyle    p_x\frac{u_yn_x}{f} - p_y(1-\frac{u_yn_y}{f}) - p_z\frac{u_yn_z}{f} + \frac df u_y \newline
\displaystyle    p_x\frac{u_zn_x}{f} - p_y\frac{u_zn_y}{f} - p_z(1-\frac{u_zn_z}{f}) + \frac df u_z
\end{pmatrix} \\
\end{align*}
$$

$$
\Rightarrow M = \begin{pmatrix}\displaystyle
1 - \frac{u_xn_x}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_xn_y}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_xn_z}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_xd}{\overrightarrow{ n } \circ \overrightarrow{ u }} \\[16pt]\displaystyle -\frac{u_yn_x}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle 1-\frac{u_yn_y}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_yn_z}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_yd}{\overrightarrow{ n } \circ \overrightarrow{ u }} \\[16pt]\displaystyle -\frac{u_zn_x}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_zn_y}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle 1-\frac{u_zn_z}{\overrightarrow{ n } \circ \overrightarrow{ u }} &\displaystyle -\frac{u_zd}{\overrightarrow{ n } \circ \overrightarrow{ u }} \\[16pt]\displaystyle
0&0&0&1
\end{pmatrix}
$$

## Punktlichtquelle
Wie bei der linearen Lichtquelle, aber der Richtungsvektor ändert sich für jeden Punkt

$$
\begin{align*}
\overrightarrow{ p } &= \begin{pmatrix}x_p\newline y_p\newline z_p\end{pmatrix} \\
\overrightarrow{ l } &= \begin{pmatrix}x_l\newline y_l\newline z_l\end{pmatrix} \\
\rightarrow \overrightarrow{ u } &= \begin{pmatrix}x_p-x_l\newline y_p-y_l\newline z_p-z_l\end{pmatrix}
\end{align*}
$$
