# Lagebeziehungen
## 1. Lagebeziehungen von Ebenen und Geraden

### Wie können eine Ebene und Gerade zueinander liegen?
* können sich schneiden, zueinander parallel sein oder die Gerade kann in der Ebene liegen
* zum Herausfinden: gleichsetzen (wenn Ebene in Parameterform) bzw. Komponenten der Geradengleichung in die Ebenengleichung einsetzen

#### Beispiel 1
Untersuchen Sie die gegenseitige Lage der Geraden $g$ und der Ebene $E$.

##### a.
$$
\begin{align*}
g: \overrightarrow{ x } &= \begin{pmatrix}2\newline 2\newline 1\end{pmatrix} + t \begin{pmatrix}1\newline -1\newline 1\end{pmatrix} \\
E: \overrightarrow{ x } &= \begin{pmatrix}1\newline 1\newline 5\end{pmatrix} + r \begin{pmatrix}2\newline 0\newline 1\end{pmatrix} + s\begin{pmatrix}1\newline -1\newline 3\end{pmatrix} \\
\overrightarrow{ x_g } &= \overrightarrow{ x_E } \\
\rightarrow \begin{pmatrix}2\newline 2\newline 1\end{pmatrix} + t \begin{pmatrix}1\newline -1\newline 1\end{pmatrix} &= \begin{pmatrix}1\newline 1\newline 5\end{pmatrix} + r \begin{pmatrix}2\newline 0\newline 1\end{pmatrix} + s\begin{pmatrix}-1\newline -1\newline 3\end{pmatrix} \\
\rightarrow L &= \left\{ \left\{r=-\frac13; s=-\frac43; t=-\frac13 \right\}\right\} \\
\left| L \right| &= 1 \\
\Rightarrow &\text{ schneiden sich} \\
\overrightarrow{ OD } &= \begin{pmatrix}2\newline 2\newline 1\end{pmatrix} + t\begin{pmatrix}1\newline -1\newline 1\end{pmatrix} ~~|~t = -\frac13 \\
&= \begin{pmatrix}\frac53\newline \frac73\newline \frac23\end{pmatrix} \\
\Rightarrow D&\left(\frac53\middle|\frac73\middle|\frac23\right)
\end{align*}
$$

##### b.
$$
\begin{align*}
g: \overrightarrow{ x } &= \begin{pmatrix}1\newline 2\newline 3\end{pmatrix} + t \begin{pmatrix}2\newline -1\newline 1\end{pmatrix} \\
E: \overrightarrow{ x } &= \begin{pmatrix}5\newline 0\newline 5\end{pmatrix} + r \begin{pmatrix}4\newline 1\newline -1\end{pmatrix} + s \begin{pmatrix}1\newline 1\newline -1\end{pmatrix} \\
\begin{pmatrix}1\newline 2\newline 3\end{pmatrix} + t \begin{pmatrix}2\newline -1\newline 1\end{pmatrix} &= \begin{pmatrix}5\newline 0\newline 5\end{pmatrix} + r \begin{pmatrix}4\newline 1\newline -1\end{pmatrix} + s \begin{pmatrix}1\newline 1\newline -1\end{pmatrix} \\
\rightarrow L &= \left\{r = t-2; s=4-2t; t\in\mathbb R\right\} \\
\rightarrow g &\in E 
\end{align*}
$$

## 2. Lagebeziehungen von Ebenen
Zwei Ebenen können zueinander *identisch* sowie *parallel* sein und sich *schneiden*.

### Parallelität
$$
\begin{align*}
E_1: x_{n_1}x + y_{n_1}y + z_{n_1}z &= \overrightarrow{ p_1 } \circ \overrightarrow{ n_1 } \\
E_2: x_{n_2}x + y_{n_2}y + z_{n_2}z &= \overrightarrow{ p_2 } \circ \overrightarrow{ n_2 } \\
\rightarrow \overrightarrow{ n_1 } &= r \cdot \overrightarrow{ n_2 } ~,\, r \in \mathbb R \backslash \{0\} \\
\end{align*}
$$

### Identisch
$$
\begin{align*}
E_1: x_{n_1}x + y_{n_1}y + z_{n_1}z &= \overrightarrow{ p_1 } \circ \overrightarrow{ n_1 } \\
E_2: x_{n_2}x + y_{n_2}y + z_{n_2}z &= \overrightarrow{ p_2 } \circ \overrightarrow{ n_2 } \\
\rightarrow \text{I. } \overrightarrow{ n_1 } &= r \cdot \overrightarrow{ n_2 } ~,\, r \in \mathbb R\\
\text{II. } \overrightarrow{ p_1 } \circ \overrightarrow{ n_1 } &= r \cdot \overrightarrow{ p_2 } \circ \overrightarrow{ n_2 }
\end{align*}
$$

### Schneiden
$$
\begin{align*}
\overrightarrow{ n_1 } &\neq \overrightarrow{ n_2 } ~,\, r \in\mathbb R \backslash \{0\} 
\end{align*}
$$
