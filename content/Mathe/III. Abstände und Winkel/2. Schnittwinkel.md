# Schnittwinkel
## 1. Zwischen zwei Geraden
Überprüfen ob ein Schnittpunkt existiert, dann Skalarprodukt zwischen Richtungsvektoren nach dem Winkel umstellen.
Wichtig: Der Schnittwinkel ist immer der kleinere der beiden Winkel.

$$ \varphi = \arccos\left( \frac{ \left| \overrightarrow{ v_1 } \circ \overrightarrow{ v_2 } \right| }{ \left| \overrightarrow{ v_1 } \right| \left| \overrightarrow{ v_2 } \right| } \right) ~,\, \varphi \leq 90 \degree $$


### Übung
#### Die Geraden $g$ und $h$ schneiden sich. Bestimmen Sie den Schnittwinkel.
$$
\begin{align*}
g: \overrightarrow{ x } &= \begin{pmatrix}2\newline 7\newline 11\end{pmatrix} + r \begin{pmatrix}3\newline 9\newline -1\end{pmatrix} \\
h: \overrightarrow{ x } &= \begin{pmatrix}0\newline 6\newline -5\end{pmatrix} + s \begin{pmatrix}1\newline 2\newline 3\end{pmatrix} \\
\varphi &= \arccos\left( \frac{ \begin{pmatrix}3\newline 9\newline -1\end{pmatrix} \circ \begin{pmatrix}1\newline 2\newline 3\end{pmatrix} }{ \left| \begin{pmatrix}3\newline 9\newline -1\end{pmatrix} \right| \cdot \left| \begin{pmatrix}1\newline 2\newline 3\end{pmatrix} \right| } \right) \\
&\approx 59,7 \degree
\end{align*}
$$

#### Geben Sie eine Formel an, mit der sich der Schnittwinkel zweier sich schneidender Geraden berechnen lässt.
$$ \varphi = \arccos\left( \frac{ \left| \overrightarrow{ v_1 } \circ \overrightarrow{ v_2 } \right| }{ \left| \overrightarrow{ v_1 } \right| \left| \overrightarrow{ v_2 } \right| } \right) $$

## 2. Zwischen zwei Ebenen
Überprüfen ob die Ebenen sich schneiden, dann Skalarprodukt der Normalen umstellen.

$$ \varphi = \arccos\left( \frac{ \left| \overrightarrow{ n_1 } \circ \overrightarrow{ n_2 } \right| }{ \left| \overrightarrow{ n_1 } \right| \left| \overrightarrow{ n_2 } \right| } \right) ~,\, \varphi \leq 90 \degree $$

## 3. Zwischen Ebene und Gerade

$$ \varphi = \arcsin\left( \frac{ \left| \overrightarrow{ n } \circ \overrightarrow{ v } \right| }{ \left| \overrightarrow{ n } \right| \left| \overrightarrow{ v } \right| } \right) ~,\, \varphi \leq 90 \degree $$
