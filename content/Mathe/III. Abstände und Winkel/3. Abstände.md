# Abstände
## 1. Abstand eines geometrischen Objektes von einer Ebene

### Punkt-Ebene
$$
\begin{align*}
P&(x_p|y_p|z_p) \\
E: d &= ax + by + cz \\
g: \overrightarrow{ x } &= \begin{pmatrix}x_p\newline y_p\newline z_p\end{pmatrix} + r \begin{pmatrix}a\newline b\newline c\end{pmatrix} \\
d &= a(x_p + ra) + b(y_p + rb) + c(z_p + rc) \\
&= ax_p + ra^2 + by_p + rb^2 + cz_p + rc^2 \\
&= ax_p + by_p + cz_p + r(a^2 + b^2 + c^2) \\
\rightarrow r &= \frac{d - ax_p - by_p - cz_p}{a^2+b^2+c^2} \\
\rightarrow \overrightarrow{ PL } &= r \begin{pmatrix}a\newline b\newline c\end{pmatrix} \\
&= \frac{ d - ax_p - by_p - cz_p }{a^2+b^2+c^2} \begin{pmatrix}a\newline b\newline c\end{pmatrix} \\
\text{Abst}(P; E) &= \left| \overrightarrow{ PL } \right| \\
&= \frac{ \left| d - ax_p - by_p - cz_p \right| }{a^2+b^2+c^2} \cdot \sqrt{a^2+b^2+c^2} \\
\Rightarrow \text{Abst}(P; E) &= \frac{ \left| d - ax_p - by_p - cz_p \right| }{\sqrt{a^2+b^2+c^2}} \\
&= \left| \frac{d - \overrightarrow{ n } \circ \overrightarrow{ OP } }{ \left| \overrightarrow{ n } \right| }\right| \\
&= \frac{\left|d - \overrightarrow{ n } \circ \overrightarrow{ OP } \right|}{ \left| \overrightarrow{ n } \right| }
\end{align*} \\
$$

### Gerade/Ebene-Ebene
Den Abstand zweier paralleler Ebenen bzw. einer zu einer Ebene parallelen Geraden und der Ebene bestimmt man, indem man den Abstand eines beliebigen Puntkes der Ebene bzw. Geraden zu der anderen Ebene bestimmt:

$$ \text{Abst}(A; E) = \frac{ \left| \overrightarrow{ OP_A } \circ \overrightarrow{ n } - \overrightarrow{ OP_E } \circ \overrightarrow{ n } \right| }{ \left| \overrightarrow{ n } \right| } \\ \begin{matrix}A&\dots&\text{Gerade bzw. Ebene} \\ P_A&\dots&\text{Punkt auf Objekt }A\\ P_E&\dots&\text{Punkt auf Ebene }E\\ \overrightarrow{ n }&\dots&\text{Normale der Ebenen }E\end{matrix}$$

### Punkt-Gerade
$$
\begin{align*}
P&(x_P|y_P|z_P) \\
g: \overrightarrow{ x } &= \overrightarrow{ q } + t \cdot \overrightarrow{ v } \\
d(t) &= \left( x_P - q_x-tv_x \right)^2 + \left( y_P - q_y-tv_y \right)^2 + \left( z_P - q_z-tv_z \right)^2 \\
d'(t) &\overset!= 0 \\
\rightarrow t &= \frac{- q_{x} v_{x} - q_{y} v_{y} - q_{z} v_{z} + v_{x} x_{P} + v_{y} y_{P} + v_{z} z_{P}}{v_{x}^{2} + v_{y}^{2} + v_{z}^{2}} \\
&= \left( \overrightarrow{ OP } - \overrightarrow{ q } \right) \circ \frac{\overrightarrow{ v }}{ \left| \overrightarrow{ v } \right|^2 } \\
\Rightarrow \text{Abst}(P; g) &= \left| \overrightarrow{ OP } - \overrightarrow{ q } - \left( \overrightarrow{ OP } - \overrightarrow{ q } \right) \circ \frac{\overrightarrow{ v }}{ \left| \overrightarrow{ v } \right|^2 } \cdot \overrightarrow{ v } \right| \\
&= \frac{ \left| \begin{pmatrix}- v_{x} \left(v_{x} \left(q_{x} - x_{P}\right) + v_{y} \left(q_{y} - y_{P}\right) + v_{z} \left(q_{z} - z_{P}\right)\right) + \left(q_{x} - x_{P}\right) \left(v_{x}^{2} + v_{y}^{2} + v_{z}^{2}\right)\newline - v_{y} \left(v_{x} \left(q_{x} - x_{P}\right) + v_{y} \left(q_{y} - y_{P}\right) + v_{z} \left(q_{z} - z_{P}\right)\right) + \left(q_{y} - y_{P}\right) \left(v_{x}^{2} + v_{y}^{2} + v_{z}^{2}\right)\newline - v_{z} \left(v_{x} \left(q_{x} - x_{P}\right) + v_{y} \left(q_{y} - y_{P}\right) + v_{z} \left(q_{z} - z_{P}\right)\right) + \left(q_{z} - z_{P}\right) \left(v_{x}^{2} + v_{y}^{2} + v_{z}^{2}\right)\end{pmatrix} \right| }{ \left| \overrightarrow{ v } \right|^2 } \\
&= \left| \overrightarrow{ PQ } - \frac{\overrightarrow{ v } \left( \overrightarrow{ v } \circ \overrightarrow{ PQ } \right)}{ \left| \overrightarrow{ v } \right|^2 } \right|
\end{align*}
$$

### Gerade-Gerade (Windschief)
$$
\begin{align*}
g: \overrightarrow{ x } &= \overrightarrow{ p } + s \overrightarrow{ u } \\
h: \overrightarrow{ x } &= \overrightarrow{ q } + t \overrightarrow{ v } \\
\overrightarrow{ OG_s } &= \overrightarrow{ p } + s \overrightarrow{ u } \\
\overrightarrow{ OH_t } &= \overrightarrow{ q } + t \overrightarrow{ v } \\
\overrightarrow{ G_sH_t } &= \overrightarrow{ q } - \overrightarrow{ p } + s\overrightarrow{ u } - t\overrightarrow{ v } \\
\text{I.}~~\overrightarrow{ G_sH_t } \circ \overrightarrow{ u } &= 0 \\
\text{II.}~~\overrightarrow{ G_sH_t } \circ \overrightarrow{ v } &= 0 \\
\end{align*}
$$

## 2. Spiegelung eines Punktes an einer Ebene
$$
\begin{align*}
E: n_xx + n_yy + n_zz &= \overrightarrow{ p } \circ \overrightarrow{ n } \\
\overrightarrow{ n } &= \begin{pmatrix}n_x\newline n_y\newline n_z\end{pmatrix} \\
\overrightarrow{ p } &= \begin{pmatrix}p_x\newline p_y\newline p_z\end{pmatrix}
\end{align*}
$$

$$
\begin{align*}
g: \overrightarrow{ x } &= \overrightarrow{ OQ } + t \overrightarrow{ n } \\
(x_Q + tn_x)n_x + (y_Q+tn_y)n_y + (z_Q+tn_z)n_z &= \overrightarrow{ p } \circ \overrightarrow{ n } \\
t_E &\colonequals t \\
\overrightarrow{ OQ } \circ \overrightarrow{ n } + t_E \left| \overrightarrow{ n } \right|^2 &= \overrightarrow{ p } \circ \overrightarrow{ n } \\
\rightarrow \frac{\left( \overrightarrow{ p } - \overrightarrow{ OQ } \right) \circ \overrightarrow{ n }}{ \left| \overrightarrow{ n } \right|^2 } &= t_E \\
\end{align*}
$$

$$
\begin{align*}
\overrightarrow{ OQ' } &= \overrightarrow{ OQ } + \underbrace{2 \cdot t_E}_t \cdot \overrightarrow{ n } \\
&= \overrightarrow{ OQ } + 2\frac{\left( \overrightarrow{ p } - \overrightarrow{ OQ } \right) \circ \overrightarrow{ n }}{ \left| \overrightarrow{ n } \right|^2 } \overrightarrow{ n } \\
&= \overrightarrow{ OQ } + 2\left( \left( \overrightarrow{ p } - \overrightarrow{ OQ } \right) \circ \frac{ \overrightarrow{ n } }{ \left| \overrightarrow{ n } \right| } \right) \cdot \frac{ \overrightarrow{ n } }{ \left| \overrightarrow{ n } \right| }
\end{align*}
$$

$$ \boxed{ \overrightarrow{ OQ' } = \overrightarrow{ OQ } + 2\left( \left( \overrightarrow{ p } - \overrightarrow{ OQ } \right) \circ \frac{ \overrightarrow{ n } }{ \left| \overrightarrow{ n } \right| } \right) \cdot \frac{ \overrightarrow{ n } }{ \left| \overrightarrow{ n } \right| } } $$
