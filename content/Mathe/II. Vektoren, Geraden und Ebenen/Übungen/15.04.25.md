### Nr. 10.
#### a.
$$
\begin{align*}
\overrightarrow{ a } \circ \overrightarrow{ b } &= a_x b_x + a_y b_y + a_z b_z \\
&= b_x a_x + b_y a_y + b_z a_z \\
&= \overrightarrow{ b } \circ \overrightarrow{ a }
\end{align*}
$$

#### b.
$$
\begin{align*}
\left( r \cdot \overrightarrow{ a } \right) \circ \overrightarrow{ b } &= r a_x b_x + r a_y b_y + r a_z b_z \\
&= r (a_xb_x + a_yb_y + a_zb_z) \\
&= r \cdot \left( \overrightarrow{ a } \circ \overrightarrow{ b } \right)
\end{align*}
$$

#### c.
$$
\begin{align*}
\left( \overrightarrow{ a } + \overrightarrow{ b } \right) \circ \overrightarrow{ c } &= (a_x + b_x)c_x + (a_y + b_y)c_y + (a_z + b_z)c_z \\
&= a_xc_x + b_xc_x + a_yc_y + b_yc_y + a_zc_z + b_zc_z \\
&= a_xc_x + a_yc_y + a_zc_z + b_xc_x + b_yc_y + b_zc_z \\
&= \overrightarrow{ a } \circ \overrightarrow{ c } + \overrightarrow{ b } \circ \overrightarrow{ c }
\end{align*}
$$

#### d.
$$
\begin{align*}
\overrightarrow{ a } \circ \overrightarrow{ a } &= a_xa_x + a_ya_y + a_za_z \\
&= a_x^2 + a_y^2 + a_z^2 \\
&= \sqrt{a_x^2 + a_y^2 + a_z^2}^2 \\
&= \left| \overrightarrow{ a } \right|^2
\end{align*}
$$

---

$$
\begin{align*}
\overrightarrow{ b } \circ \overrightarrow{ OP } &= \overrightarrow{ b } \circ \left( \frac12 \overrightarrow{ b } + \overrightarrow{ d } \right) \\
&= \frac12\left| \overrightarrow{ b } \right|^2 + \overrightarrow{ b } \circ \overrightarrow{ d } \\
&= \frac12\left| \overrightarrow{ b } \right|^2 \\
&= \frac12\left| \overrightarrow{ a } + \overrightarrow{ OC } \right|^2 \\
&= \frac12(\sqrt2\left| \overrightarrow{ a } \right|)^2 \\
&= \left| \overrightarrow{ a } \right|^2
\end{align*}
$$

Da die Vektoren $ \overrightarrow{ b } $ und $ \overrightarrow{ d } $ in einem rechten Winkel zueinander stehen, ist das Skalarprodukt $\displaystyle \overrightarrow{ b } \circ \overrightarrow{ d } $ gleich null. Demnach lässt sich der gegebene Term zu einer Form vereinfachen, die nur von den Seitenlängen der Grundfläche abhängig sind.
