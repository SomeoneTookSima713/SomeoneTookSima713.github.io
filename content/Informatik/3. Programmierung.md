## Rekursive und iterative Algorithmen
###### Beispiel: Fibonacci-Zahlen

Die Fibonacci-Zahlen sind eine Reihe an Zahlen, die rekursiv definiert wurden: Man setzt die erste und zweite Zahl gleich eins ($f_1 = 1; f_2 = 1$) und berechnet jede andere Zahl als Summe der zwei vorherigen Zahlen: $f_n = f_{n-1} + f_{n-2}$

Diese Zahlen kann man auch mit einer Python-Funktion berechnen:
```python
def fib(n):
    if n == 1 or n == 2:
        return 1
    else:
        return fib(n-1) + fib(n-2)
```

Diese Funktion ist *rekursiv*, da sie sich selbst wieder aufruft.

Rekursive Funktionen haben einen *Rekursionsanker* und einen *Rekursionsaufruf*. Der Rekursionsanker ist in unserer Funktion der `if`-Block, da der eine Basis für die Werte gibt. Der Rekursionsaufruf ist dann im `else`-Block, da hier die Funktion wieder aufgerufen wird.

Man kann diese Funktion aber auch *iterativ* definieren:
```python
def fib(n):
    val1 = 1
    val2 = 1
    for _ in range(n-2):
        neueZahl = val1+val2
        val1 = val2
        val2 = neueZahl
    return val2
```

Diese Funktion ist iterativ, da sie sich *nicht* selbst aufruft.

### Vortrag Bitonic Mergesort
#### Erklärung
* basiert auf sog. *Bitonischen Sequenzen*
    * sind Zahlenfolgen, die aus zwei unterschiedlich monotonen Teilen bestehen
* besteht aus Blöcken, die jeweils eine bitonische Sequenz als Eingabe nehmen und eine sortierte Sequenz ausgeben
* tolle Eigenschaft: jedes Paar aus zwei Zahlen ist immer eine bitonische Sequenz
    → zuerst werden alle benachbarten Zahlenpaare in der unsortierten Liste in diese Blöcke eingegeben und man kriegt sortierte Zahlenpaare raus
    * Sortierung ist für jedes gerade Zahlenpaar (2., 4. usw.) genau andersherum als für jedes ungerade Zahlenpaar
        → benachbarte Zahlenpaare bilden so *wieder* eine Bitonische Sequenz und können jeweils in einen weiteren Block eingegeben werden, der so insgesamt eine Sequnez von *4* Sortierten Zahlen ausgibt (auch wieder immer in abwechselnder Reihenfolge)
* dieses Vorgehen wird so oft wiederholt, bis ein Block die ganze Liste als Eingabe nimmt und die vollständig sortierte Liste wieder ausgibt

* jeder Pfeil vergleicht zwei Zahlen miteinander und bringt sie in so die Reihenfolge, so dass bei der Pfeilspitze die jeweils größere Zahl ist
* jede rote Box besteht aus Pfeilen, die in eine Richtung zeigen
    * wenn die Eingaben in eine rote Box eine bitonische Sequenz formen, besteht die Ausgabe aus zwei neuen bitonischen Sequenzen (die eine Sequenz enthält dann nur Elemente, die kleiner oder gleich jedem Element in der anderen Sequenz sind)
* jede blaue/grüne Box besteht aus roten Boxen
    * die Boxen jeder "Schicht" sind halb so groß wie die der vorherigen "Schicht"
    * wenn Eingabe eine bitonische Sequenz ist, ist die Ausgabe vollständig sortiert (bei blauen Boxen in die eine Richtung, bei grünen in die Andere)
    * die ersten dieser Boxen nehmen jeweils zwei Elemente als Eingabe
        * Vorteil: Ist garantiert eine bitonische Sequenz, damit ist die Ausgabe garantiert vollständig sortiert

#### Codebeispiel
```python
def comp_and_swap(items: list[int], ind1: int, ind2: int, ascending: bool):
    if (items[ind1] > items[ind2]) == ascending:
        items[ind1], items[ind2] = items[ind2], items[ind1]

def bitonic_merge(items: list[int], low: int, length: int, ascending: bool):
    if length > 1:
        middle = int(length / 2)
        for i in range(low, low + middle):
            comp_and_swap(items, i, i+middle, ascending)
        bitonic_merge(items, low, middle, ascending)
        bitonic_merge(items, low+middle, middle, ascending)

def bitonic_sort(items: list[int], low: int, length: int, ascending: bool):
    if length > 1:
        middle = int(length / 2)
        bitonic_sort(items, low, middle, True)
        bitonic_sort(items, low+middle, middle, False)
        bitonic_merge(items, low, length, ascending)

my_list = [5, 3, 10, 25, 2, 18, 29, 0]
bitonic_sort(my_list, 0, len(my_list), True)
print(my_list) # [0, 2, 3, 5, 10, 18, 25, 29]
```
